# 超星视频与 PDF 连播

在超星网页版打开一个章节，点击「开始连播」，脚本会静音播放视频并逐页展示 PDF。章节目录显示完成后，脚本按目录顺序打开下一节。遇到章节测验会停下。

## 在 Microsoft Edge 安装

1. 点击本仓库的 **Code → Download ZIP**，将 ZIP 解压到一个打算长期保留的文件夹。
2. 在 Edge 地址栏打开 `edge://extensions`，开启「开发人员模式」，点击「加载解压缩的扩展」。
3. 选择**直接包含 `manifest.json` 的文件夹**。扩展列表中应出现「超星视频与 PDF 连播」。
4. 刷新超星页面。在课程首页会看到打开章节的提示；进入具体章节后，右下角会出现「开始连播」。

更新时，将新版文件解压覆盖到同一目录，在扩展管理页点击该扩展的「重新加载」，再刷新课程页。

## 通过油猴安装

已安装 Tampermonkey 的用户可打开 [用户脚本](./chaoxing-study.user.js)，点击 **Raw**，在油猴弹出的安装页确认。如果浏览器只显示源码，在油猴里新建脚本，用完整源码替换模板，保存后刷新章节页。两种安装方式任选一种，同时启用可能重复处理 PDF 消息。

## 使用

- 登录超星，在章节目录里选定起始小节，点击右下角「开始连播」。视频会先静音，再以播放器当前速度播放。
- PDF 默认每页停留 **12 秒**，可在面板中设置为 1–600 秒。脚本显示当前页和总页数，并将末页滚到页底。
- 章节完成后，脚本从目录选择紧邻的下一项。遇到测验或无法确认完成状态时，面板会显示停止原因。
- 点击「暂停连播」可停止自动操作并暂停当前视频。再次启动会重新检查当前章节，PDF 从第一页开始。

## 常见问题

**看不到面板**  请确认课程页与扩展位于同一个浏览器配置中，安装或更新后刷新页面。使用油猴时，请检查脚本已启用并有权在超星网站运行。[Tampermonkey 用户脚本权限说明](https://www.tampermonkey.net/faq.php?q=Q209)

**PDF 阅读器未响应**  PDF 阅读器可能加载在单独的超星子域名。检查扩展能否在该阅读器所在域名运行，并确认文档本身能正常打开。

**视频播完后仍停在本节**  查看右侧目录是否还有未完成项。视频和文档可能分别计数，其他任务需要在课程页按提示处理。

## 适用范围与验证

本项目适配超星网页版的章节播放器和分页 PDF 阅读器。使用时请遵循所在学校和课程的学习要求。扩展使用现有登录页面，学习进度由超星页面记录。
